# 💜 Dating Recommendations – Matching System

## Project Overview
This project explores a dating app dataset and develops a simple content-based recommendation system to suggest compatible user profiles based on shared interests and profile characteristics.

## Dataset
- **File:** `dating_app_dataset.csv`
- **Records:** 500 user profiles

## Key Features
- Exploratory Data Analysis (EDA)
- User demographics and interest analysis
- Data quality checks and visualizations
- Content-based profile matching
- Top 5 profile recommendations
- Recommendation score visualization

## Conclusion
This project demonstrates how exploratory data analysis and simple matching techniques can be used to build an interpretable recommendation system.
